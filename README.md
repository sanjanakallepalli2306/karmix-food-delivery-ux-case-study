# Foodie — Food Delivery App UX Case Study

**Karmix Tech Internship — Project 4**

A responsive HTML/CSS/JavaScript presentation of a Food Delivery App UX case study.

## Project scope
- User research
- UX problem framing
- User persona
- User flow
- Low-fidelity wireframe representation
- High-fidelity UI screen presentation
- Design system
- Prototype section
- Expected/projected outcomes

## Files
- `index.html` — case study website
- `styles.css` — responsive styling
- `script.js` — small prototype-link interaction

## How to run
Open `index.html` in a browser.

## Before GitHub submission
1. Replace the prototype button link in `index.html` with your actual Figma prototype URL.
2. Add your actual Figma project link to the README if required.
3. If your research/result percentages are based on real user testing, document the sample and method. Otherwise keep them labelled as targets/projected outcomes.
4. Add your final screenshots and any original design assets if required by the internship.
